Built-in pacing, a usage report, plain-language errors, many items per run, and a contents command.

## New

- **--list <file>:** runs a read or download command once per line of a file (desc, changelog, files, archived-files, file-note, contents, dl-file, reqs, dependents, list-mods, save-desc) and prints one JSON object per line. A rate limit stops the run so it can be resumed.
- **contents <mod> <file#>:** the files inside one archive, with its plugins, BSAs and whether it holds exactly one plugin.
- **--usage** (also --rate, --rates, --limits, or --limit on its own): the requests of the last hour by API, what Nexus Mods says is left of the limits, and uploads in their own section. --verbose breaks it down by command; --per s, m, h or d sets the window.
- **Pacing:** queries 1 per 3 seconds, downloads 1 per 4 seconds, uploads 1 per 31 seconds, also across separate runs. --interval <seconds> overrides it.
- **dl-file:** --skip-existing leaves a file that is already there, --max-size skips bigger files, and the output always gives the saved file name.
- **reqs:** has_requirements says in one word whether the mod lists anything it needs.
- **NEXUS_GAME_ID:** sets the default game (a domain or a game number).
- **--help:** names the API each command uses and lists the rate limits; --help --verbose shows the calls each command makes and how many runs the limits allow.

## Changed

- **Errors** are in plain words. A rate limit exits with code 3, says whether Nexus Mods or Cloudflare refused the request, and gives retry_after.
