Replace a mod's description page from a BBCode file, upload files, list a user's mods, and read a page's permissions.

## New

- **set-desc:** replaces a description page with a BBCode text file. The current page is backed up first, HTML that Nexus would show as literal text is refused, and the page is read back afterwards to confirm it.
- **save-desc:** saves a description page as a BBCode text file, ready to edit or restore.
- **upload-file:** uploads an archive under 100 MiB as a new file, or with --replaces as a new version of an existing one. --dry-run checks everything without uploading.
- **list-mods:** lists the mods a user uploaded for a game, newest first.
- **permissions:** now takes a mod id or a page address and returns the page's Permissions and credits section. --html reads a page saved from a browser, which unpublished pages need.

## Fixed

- Blank lines are kept on pages stored with several line breaks in a row.
