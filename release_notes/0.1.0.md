First release: read a Nexus Mods page's information from the command line, as JSON.

## New

- **desc, changelog:** a mod's description and its changelog per version.
- **files, archived-files:** a mod's files grouped by category, with label, dates and notes.
- **file-note:** the note on one file.
- **dl-file:** downloads one file (needs a Premium account).
- **reqs, dependents:** what a mod requires, and the mods that require it. At most 200 entries per call, with --offset to continue.
- **permissions:** what the API can tell about permissions, with a link to the page's checklist.

## Setup

Set the NEXUS_API_KEY environment variable to your personal API key from nexusmods.com > Site preferences > API Keys.
