File lists now work on unpublished mods, and no longer need an API key.

## Changed

- **files, archived-files, file-note:** use Nexus's GraphQL file list, which takes one request, needs no API key and also covers unpublished mods.
- **file_name** in those commands' output is null for newer uploads, where Nexus doesn't report it in the file list. dl-file still saves files under their real names.
